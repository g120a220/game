# 教材與來源政策

五題 seed 是原創功能示範，沒有出版社對應，不是已核驗的一年級完整教材。正式課程數目前為零。科目選項只提供規劃中的選擇；未建置選項明示尚未準備，不能視為已核實的年級適用科目。

來源優先序：國家教育研究院課綱、教科用書審定資訊、出版社合法公開目錄、正式學校選書資料、有授權或人工確認內容。起始參考網址：

- https://www.naer.edu.tw/PageSyllabus?fid=52
- https://textbooks.naer.edu.tw/BookSrhR.aspx
- https://www.knsh.com.tw/service/version

本次未查核這些網站中的實際章節與版次，沒有將其標示為已核驗。後台 JSON 格式範例中的來源 URL 是格式展示，不能作為題目適用性或授權證據。

每項教材保留來源、查閱時間、授權說明、學年度、出版社、版次、年級、學期與映射。人工確認真實章節後才建立，不虛構真實出版社單元名稱。原創題需有答案驗算、適齡性、提示、解說、知識點與難度審查。

題目匯入 → 草稿 → 不同帳戶人工查核與審查紀錄 → 編輯建立單題發布紀錄。程式只驗證流程約束，無法自動保證審查員的聲明屬實。自動測試中的來源核驗聲明僅存在隔離測試資料庫，不是正式教材審查。

單題發布不代表一整冊或出版社版本已建置。完整版本審查及正式課程取題尚未啟用。待來源證據齊全後，優先完成一年級數學一個出版社版本，逐小節建立與查核，再開放正式課程入口。
