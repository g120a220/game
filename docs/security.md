# 安全邊界與上線條件

本版只使用固定示範角色，不收集真實姓名、生日、學校、定位或第三方分析。示範家長授權是流程驗證，並非法律或正式身分驗證。

本地模式需明確設定 `LOCAL_DEMO_MODE=true`，服務只綁定 127.0.0.1，Host 必須為 loopback。正式非本地 API 預設回覆 503；沒有 Supabase 時不提供可公開的假登入。不可自行把服務改為公開綁定或透過代理轉送此示範模式。

session 使用 256-bit 隨機值、伺服器僅存 SHA-256、HttpOnly／SameSite Strict cookie，HTTPS 時加 Secure，8 小時到期。每個修改請求驗證 Origin 與實際 Host。角色、家庭、session 所有權、判分、上限、點數皆由服務端決定。SQL 值使用參數，metadata 識別字來自固定 allowlist，交易防止重複獎勵及餘額超支。

已測試家庭資料隔離、角色越權、無家長同意、跨來源請求、重複作答／兌換、無效選項、未審核發布。PostgreSQL 全部 public 表啟用 RLS，用戶端無直接寫權，答案及草稿無讀權；家庭資料僅授權相同家庭及角色讀取。雲端服務層必須沿用相同授權並使用原子交易。

仍須完成：正式 Auth／受監護子帳戶、撤回同意、匯出／刪除、帳戶復原、管理員 MFA、速率限制、強健 CSP、伺服器大小限制、備份與復原、操作告警、相依套件及部署稽核。沒有宣稱符合特定法律或已可收集真實兒童資料。

無廣告 SDK、行為追蹤、付款或現金兌換。每日完成只發一次 10 顆星星，連續七日上限 80，每日最多兩次有限任務；沒有連續登入獎勵。暫停不停止伺服器任務時鐘；滿 15 分鐘不再接受作答，畫面提醒休息。首版無法判定使用者實際離開螢幕，正式使用時間控制仍待強化。
