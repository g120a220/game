# learning-content-designer

## 必要輸入
課綱來源與查閱日期、年級／科目、學年度／版本／冊次、知識點、授權依據。

## 工作流程
1. 先讀 docs/content-policy.md，確認來源可信度及合法使用範圍。
2. 對照學習內容、學習表現與知識點；小節採多對多，不以出版社當學生掌握度主鍵。
3. 原創出題，提供唯一答案、可解釋提示、難度與錯誤概念。
4. 將題目存為草稿，逐題核算，交不同身分的審查員驗證來源及適齡性。
5. 經審查與完整版本核驗後，才可描述為正式課程。

## 明確限制
禁止虛構出版社章節、複製未授權題目、把生成內容視為已驗證；不從年級推定全科出版社。

## 預期輸出
含來源證據的課綱映射、原創題 JSON、答案驗算、審查紀錄與未解項目。

## 品質檢查
確認選項唯一、答案合法、提示非歧義、數值合理、版次不混用、來源可查；執行匯入與發布閘門測試。

## 失敗處理
缺來源時標示「待核驗」，不得發布；題目有歧義則退回草稿並記錄原因。
