# reward-economy-designer

## 必要輸入
獎勵種類、發放條件、台北時區、每日／七日上限、角色與家庭邊界。

## 工作流程
1. 先定義幣別與不可兌現限制，將養成星星及家庭可用餘額分開呈現。
2. 所有餘額由不可變 ledger 與兌換紀錄推導，禁止信任客戶端金額。
3. 將領取條件、唯一鍵、上限檢查及入帳放在同一交易。
4. 兌換驗證家庭、餘額、冪等鍵及扣點，家長確認履行。
5. 測試重送、並發、跨日、跨家庭及餘額不足。

## 明確限制
首版禁止現金兌付、隨機付費獎品與答對率導向發獎；不可改寫既有交易掩蓋錯誤。

## 預期輸出
規則表、ledger 結構、唯一約束、交易實作與競態／邊界測試。

## 品質檢查
確認 Taipei 日界、每日只領一次、七日上限、重送不重扣、跨家庭不可見、伺服器判定金額。

## 失敗處理
交易失敗全部回滾；對帳異常暫停兌換並保留證據，不補寫假交易。
