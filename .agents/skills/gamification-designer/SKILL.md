# gamification-designer

## 必要輸入
年齡層、學習目標、任務題數、裝置與輸入方式、現有獎勵規則。

## 工作流程
1. 先決定學習行為，再選擇最少必要的遊戲回饋。
2. 設計 10–15 分鐘任務及明確終點。
3. React 管理可及的答題介面，Phaser 僅管理可丟棄的地圖視覺；規則在服務層。
4. 提供暫停、自然結束、鍵盤與觸控等價操作。
5. 以遊玩測試驗證錯題回饋、休息提示與 reduced-motion。

## 明確限制
禁止無限刷題、登入連續獎勵、看廣告換獎、付費抽獎、懲罰未登入或恐嚇寵物消失。

## 預期輸出
學習循環、狀態轉移、時間預算、輸入清單、資產清單、驗收案例。

## 品質檢查
確認結束可達、頁面重整可恢復、場景銷毀無洩漏、答錯不羞辱、停止沒有損失。

## 失敗處理
回饋鼓勵過度使用則降低頻率；Canvas 失敗時保留 DOM 操作，不阻擋學習。
